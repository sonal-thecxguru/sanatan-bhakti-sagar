Privacy Policy

Last updated: 15 November 2026

This policy describes how the "Sanatan Bhakti Sagar" app ("the app") handles data. The app is a private tool used only by the owner of the Sanatan Bhakti Sagar YouTube channel to manage that channel.

Data the app accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API to read and update the owner's own channel data: videos, titles, descriptions, tags, thumbnails, playlists and basic channel statistics.

How the data is used

Data is used only to manage the owner's own YouTube channel. It is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens are stored only on the owner's own computer. No data is stored on any external server operated by the app.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
